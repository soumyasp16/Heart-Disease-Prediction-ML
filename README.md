# Heart Disease Prediction Using Machine Learning ❤️

## Project Overview

This project aims to predict potential heart disease using Machine Learning algorithms. It uses patient health information to identify patterns associated with heart disease.

The project includes data analysis, data preprocessing, model training, model evaluation, model comparison, and recommendations for hospitals.

**Project ID:** PRCP-1016

**Domain:** Healthcare

## Objectives

- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess patient data.
- Analyze important health-related features.
- Develop multiple Machine Learning models.
- Compare model performance.
- Identify a suitable candidate model.
- Provide recommendations for hospitals.

## Dataset Features

- Age
- Sex
- Resting Blood Pressure
- Serum Cholesterol
- Chest Pain Type
- Maximum Heart Rate
- Exercise-Induced Angina
- Fasting Blood Sugar
- Resting ECG Results
- Number of Major Vessels
- ST Segment Slope
- Oldpeak
- Thalassemia Test Results
